# Frozen corpus — AI coding tools, as of 2025-06-11 (hindcast vantage)

Nothing in this file is dated after 2025-06-11. This is the world the
hindcast engine is allowed to know.

## Products and players (state of play, June 2025)

- GitHub Copilot: largest installed base; agent mode shipped in preview
  earlier in 2025; enterprise seats growing; Microsoft Build 2025 announced
  a Copilot coding agent for issue-to-PR work.
- Cursor (Anysphere): fastest-growing AI IDE; reported ~$500M ARR run-rate
  in spring 2025 press; raised at ~$9-10B valuation reports in May 2025.
- Claude Code (Anthropic): terminal-first agentic coding tool, GA alongside
  Claude 4 models (Opus 4 / Sonnet 4, released May 2025).
- OpenAI Codex: cloud software-engineering agent launched May 2025 inside
  ChatGPT (research preview), running tasks in sandboxed repos; separate
  open-source Codex CLI released April 2025.
- Windsurf (formerly Codeium): reports in April-May 2025 of an OpenAI
  acquisition agreement around $3B; not closed as of this vantage.
- Devin (Cognition): autonomous-engineer positioning; priced enterprise
  pilots; mixed independent evaluations through 2025H1.
- JetBrains, Sourcegraph (Amp), Google (Jules agent announced at I/O May
  2025), Amazon (Q Developer): all shipping or previewing agentic coding.

## Models (as of vantage)

- Anthropic: Claude Opus 4 / Sonnet 4 (May 2025) — strong SWE-bench results.
- OpenAI: GPT-4.1 family (April 2025), o3/o4-mini reasoning models (April
  2025); codex-1 variant powering Codex.
- Google: Gemini 2.5 Pro (I/O May 2025) with strong coding marks.
- Open-weight: DeepSeek-R1 (Jan 2025) reset price expectations; Qwen 2.5
  coder variants widely used.

## Structural facts already determined at vantage

- SWE-bench Verified is the de facto agentic coding benchmark; top reported
  scores around 70-75% by mid-2025.
- Enterprise procurement cycles for dev tooling run 3-9 months; 2025 budget
  cycles were set in late 2024.
- GitHub Universe is scheduled for late October 2025; AWS re:Invent for
  early December 2025 (annual cadence, already calendared).
- Apple WWDC June 2025: Xcode 26 announced with built-in support for
  multiple LLM providers (incl. Claude) for coding assistance.
- US AI policy: no federal statute restricting code-gen tools as of vantage.
