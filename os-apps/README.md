# Repo-Local Paw Apps

Genesis is the canonical source for production TemperPaw app bundles.

This `os-apps/` directory remains only for bootstrap, migration, local
development, and tests while canonical Genesis refs are published and pinned. It
is not a production app catalog and it is not an app-source mirror.

Production TemperPaw instances should install configured pinned Genesis refs and
recover already-installed app state from the backing Temper store.
