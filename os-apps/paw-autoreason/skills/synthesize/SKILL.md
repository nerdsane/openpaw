# Synthesize (Autoreason)

How to merge two versions without seeing the critique that produced the revision.

## Process

1. **Read Version A** — the incumbent
2. **Read Version B** — the revision
3. **Merge** — produce Version AB that takes the best from both:
   - Where B improves on A, keep B's version
   - Where A is stronger, keep A's version
   - Where they complement each other, combine them
4. **Write Version AB** to paw-fs

## Rules

- **You don't know WHY they differ**. You never see the critique. Judge purely on quality.
- **Version AB must be a complete artifact**, not a patchwork. It should read as a coherent whole.
- **Don't just pick one**. The point of synthesis is to combine strengths. If you can't find complementary elements, explain why in your notes.
- **Synthesis wins ~50% of rounds** — it's the primary improvement driver in autoreason. Your work matters.
- **Don't hedge**. Make clear choices about which version handles each section better.

## Output

Write Version AB to paw-fs. It should be a complete artifact that represents the best synthesis of both inputs.
